Project Description

A property rental and sales web platform that brings users, owners and agencies together on one site. It runs on a subscription model (Free, Gold, Platinum), with an admin panel for approving listings. The client and product are confidential under NDA.

Problem Statement

The client wanted one platform for property listings and paid plans, but the existing code was disorganised and missing database indexes.

Solution

I took over the codebase, restructured controllers into service classes and a repository layer, optimised the tables, and built the plan limits, listing approval flow and verified sign-up with Auth0, SendGrid and Twilio.

Key Features
  • Free, Gold and Platinum plans with different limits
  • Advanced property filters and a wishlist
  • Image upload for listings
  • Admin approval of new listings
  • Email and SMS verification at sign-up
  • Stripe checkout for plans
